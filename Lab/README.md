## 📁 Folder Structure

* **[`Programs/`](Programs/)**: Contains all 40 verified Python programs along with dependencies, test assets, and the interactive runner.
* **[`outputs/`](outputs/)**: Contains high-resolution output screenshots from all 40 experiments. (👉 **[Browse Full Visual Output Gallery](outputs/README.md)**)

---

## 🚀 Quick Start & Execution

Navigate to the `Programs` directory:

```bash
cd Programs
```

### Run via Interactive Launcher:
```bash
python run_all.py
```
*Enter any experiment number from `1` to `40` to run and view the live OpenCV window.*

### Run Individual Programs:
```bash
python exp01_grayscale.py
python exp15_harris_corner_detection.py
python exp27_face_detection.py
python exp40_video_text_extraction.py
```
